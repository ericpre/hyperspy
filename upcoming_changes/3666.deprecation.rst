The :meth:`~.events.Event.trigger`, :meth:`~.events.Event.suppress`, :meth:`~.events.Event.suppress_callback`, and ``connect(kwargs=...)`` methods now emit a ``VisibleDeprecationWarning``. Use :meth:`~.events.Event.emit`, :meth:`~.events.Event.blocked`, the guard-flag pattern, and explicit lambda wrappers instead. The deprecated methods will be removed in HyperSpy 3.0. Downstream libraries should migrate to the new API.
